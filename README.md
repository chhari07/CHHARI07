## `01` About Me

> Full-stack and agentic AI developer from Guna, Madhya Pradesh. I build systems that
> put AI to work on real workflows — multi-agent pipelines, orchestration layers, and
> the unglamorous infrastructure underneath them. Currently shipping products for
> tier-2/3 Indian commerce, where the constraint isn't compute, it's connectivity.

**What drives me** — I care about the gap between a demo and a system that survives
production. State machines over vibes, integer paise over floats, typed contracts over
hope. Open to Agentic AI / LLM / Founding Engineer roles in Gurgaon, Bangalore, or remote.

### ScanCart.ai
**Counterfeit detection for Indian e-commerce**

Chrome extension running five parallel LangGraph agents against a live product
listing — seller history, price anomaly, review authenticity, image forensics, and
listing-text signals — fused into a weighted Trust Score.

**Impact**
- Selected for the Rajasthan AI Builders Pitch-a-Thon, 2026
- Sub-second verdicts via parallel agent fan-out
- Maps to Consumer Protection Rules 2020 / ONDC trust layer

`LangGraph` `Claude API` `TypeScript` `Chrome MV3` `FastAPI`

</td>
<td width="50%" valign="top">

### CloseBy
**Hyperlocal shop discovery and ordering**

Production platform connecting Guna shoppers to neighbourhood stores. Geohash
proximity search, a formal eight-state order machine, and money handled as integer
paise end to end.

**Impact**
- Live deployment serving a real tier-3 market
- Clerk ↔ Firebase auth bridge with zero desync
- Order state machine with enforced legal transitions

`Next.js 15` `Firestore` `Clerk` `TypeScript` `Tailwind`

</td>
</tr>

### Orderly
**WhatsApp-first ordering and payments**

`Chat to cash.` — Ordering rails for local shops where WhatsApp *is* the internet.

**Impact**
- Turborepo monorepo, BullMQ job queues on Redis
- Drizzle ORM over Postgres, Razorpay settlement
- Idempotent webhook handling with replay safety

`Turborepo` `BullMQ` `Drizzle` `PostgreSQL` `Razorpay`

- Structured audit trail for every agent decision

`LangGraph` `Python` `Next.js` `Claude API`
